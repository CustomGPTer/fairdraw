# Fairdraw

Fairdraw is a free random picker for Android: numbers and lottery lines, real 3D dice, coins, cards, a spinning wheel, pick a name, teams, raffles, whose turn and passwords. Every pick is cryptographically fair. No adverts, no account, no internet.
